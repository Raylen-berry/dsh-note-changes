# 笔记库

在 DSH Desktop 的会话里**阅读、编辑和整理本地 Markdown 笔记**。左边找文件，中间读写，右边查看大纲与双链；需要时同步到 GitHub，或让模型收录并引用创作要求。

插件名 `dsh-note-changes` · 入口 **已有会话 → 笔记** · 设置 **设置 → 笔记库**

[安装](docs/安装.md) · [开始使用](docs/使用.md) · [两台电脑同步](docs/同步.md) · [文档导航](docs/README.md)

## 可以做什么

| 功能 | 具体用途 |
| --- | --- |
| **找笔记** | 浏览本地目录，搜索标题与正文，筛选标签和属性 |
| **读笔记** | 阅读 Markdown、公式和本地附件，沿双链查看相关内容 |
| **写笔记** | 原文编辑、快捷保存，新建空白／每日／会议笔记 |
| **整理关系** | 查看大纲、出链、反向链接、局部关系图和孤立笔记 |
| **处理保存冲突** | 对照磁盘新版与草稿，逐段选择后再保存 |
| **跨电脑继续写** | 上传本机笔记、下载 GitHub 更新，查看改动历史 |
| **积累创作记录** | 保存要求、偏好与案例，按适用范围引用到任务中 |

这里使用普通 Markdown 文件，可与 Obsidian 共用一个笔记库。Obsidian 的第三方插件、Canvas、Dataview 等能力不包含在这个工作区里。

## 第一次使用

1. 按[安装说明](docs/安装.md)安装，等正在执行的任务结束后重启 DSH Desktop。
2. 在已有会话打开 **笔记**，进入设置，选择本机笔记库文件夹并点 **应用连接**。
3. 打开一篇笔记；需要修改时切到编辑器，点 **保存** 或按 **Ctrl/Cmd+S**。
4. 在设置里核对 **会话结束时记录要点** 开关；只想手动写笔记时可以关闭它。

**草稿暂存不等于保存到文件。** 保存会写入本机文件，并只提交当前文件、尝试推送；推送失败时本地内容仍保留。两台电脑切换前后按[同步说明](docs/同步.md)操作。
