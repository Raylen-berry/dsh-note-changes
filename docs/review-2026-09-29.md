# 笔记工作区改版记录

## 本次完成

旧实现把笔记当成聊天区的辅助浮窗，只能从 Git 提交里找笔记，输入条按钮实际只控制开关。现在注册 Desktop 的根级 `main` 页面和 `sidebar.panellist` 导航，左侧打开完整笔记库；删除旧浮窗、拖动、气泡避让、输入条开关及其重复状态。

目录读取当前文件系统，未提交笔记也能找到。支持正文搜索、常用 Markdown 阅读、双链和同名候选、大纲、反向链接、原文编辑、快捷保存与草稿恢复。改动历史和配置成为独立栏目。手动编辑使用版本核对和宿主原子写入，超长文件禁止截断保存。同步提交使用 `--only -- <当前文件>`，保留其他已暂存工作，并按库串行同步。

代码拆成工作区、Markdown、样式、文件访问四个职责；生成文件检查可防止源码与发布文件不同步。Git 日志读取复用同一执行路径，检索合并并发请求并使用短期缓存。
