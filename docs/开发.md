## 构建与离线检查

```powershell
npm run check
npm test
node tools/run-all.mjs --list
```

离线检查不需要安装额外依赖。总入口包含 3 项语法检查和 10 套离线测试；逐套件条数以 `npm test` 输出为准。

Git 传输检查使用临时裸仓库与两个克隆模拟两台电脑；其余使用隔离笔记库和宿主服务夹具，不读写真实笔记，也不调用模型。CI 使用 Windows、Node.js 20／22／24，配置见 [ci.yml](../.github/workflows/ci.yml)。

修改客户端片段后先执行 `npm run build`，再运行检查；`npm run check` 会核对生成文件是否与源码一致。

## 浏览器检查

可用 `npm run test:browser` 检查阅读、创建、合并、连接、同步界面与布局。这些脚本需要已有 Playwright 和 React 资源，可通过以下环境变量选择：

| 变量 | 用途 |
| --- | --- |
| `DNC_PLAYWRIGHT_MODULE` | Playwright 模块入口 |
| `DNC_REACT_ROOT` | React 资源所在目录 |
| `DNC_BROWSER` | 浏览器 channel，Windows 默认 Edge |
| `DNC_SCREENSHOTS` | 检查截图输出目录 |

使用前检查脚本的默认本机路径；它们不是离线总入口的一部分。浏览器检查使用临时笔记库和模拟同步，不能代替正式 Desktop 重启后的集成验收。

当前挂载声明见 [cordis.patch.yml](../cordis.patch.yml)。发布文件需包含拆分后的 `docs/`，可用 `npm pack --dry-run --ignore-scripts` 查看清单。
