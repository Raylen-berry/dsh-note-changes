# 设置、路径与换机

[返回首页](../README.md) · [文档导航](README.md)

## 两种路径配置

页面的 **指定笔记库文件夹** 保存在本机浏览器，并在页面请求中传给宿主；**跟随本机配置** 则不传页面覆盖路径。两种模式点击 **应用连接** 后生效。

模型工具和自动引用不读取浏览器的这份选择。需要它们使用同一个库时，给工具显式 `vault`，或配置宿主的 `DNC_VAULT`／指针文件。

宿主路径按以下顺序选择：

1. 路由或工具的显式路径，包括页面传入的覆盖路径。
2. 宿主环境变量 `DNC_VAULT`。
3. `DSH_HOME/dsh-note-changes/vault.txt` 的第一条非空、非注释路径。
4. 在默认库中读到的 `00-索引/插件设置.md` 的 `vault` 值。
5. 当前源码的默认值 `E:/vault`。

默认值不是你机器已有笔记库的自动探测结果。换机后应明确连接自己的目录。本机前三档不会被 Git 同步回来的旧机器路径覆盖。

指针文件的查找优先使用宿主进程中的 `DSH_HOME`，缺省退到 `%APPDATA%/dsh-desktop/harness`。Desktop 实际传入的环境可能不同，应以实际生效路径为准，避免只复制旧机器的目录。

## 设置与数据在哪里

| 位置 | 内容与迁移方式 |
| --- | --- |
| 笔记库中的 Markdown 和附件 | 主要数据；由自己的备份或 Git 同步保留 |
| `00-索引/插件设置.md` | 设置 frontmatter；可随笔记仓库迁移 |
| `00-收件箱/日记/` | 模型追加要点与自动存根 |
| `40-提示词/` | 创作要求、偏好与参考记录 |
| 本机浏览器 `localStorage` | 页面连接路径、收藏、最近打开；不随 GitHub 迁移 |
| 本机浏览器 `sessionStorage` | 未保存草稿；当前会话暂存，不代替备份 |
| 宿主内存 | 索引缓存、同步回执、自动引用去重状态；重启后重新建立 |

插件不修改 `.obsidian/`。设置页写回只更新指定字段，其他属性和正文保留。

「会话结束时记录要点」缺省开启，控制日记工具与自动存根；关闭不影响手动编辑和创作记录。`creativeContext: off` 单独控制自动引用，见[创作](创作.md)。

当前设置页保留「允许检索笔记」对应的 `scanVault` 字段，但当前浏览和检索入口没有据此禁用读取；不能把这个字段视为停用所有读取的开关。

## 自动引用诊断

默认写入 `%TEMP%/dsh-note-changes/creative-context.json`，可用 `DNC_CONTEXT_DECISION_DIR` 改目录。只记录会话标识、计数、完整性与注入状态，不记录要求正文。

多个会话共用这一份最新决策文件，它是本机临时诊断，不是历史日志；离线检查使用独立诊断目录，不能把测试记录当作真实会话的证据。

## 到另一台电脑

克隆同一个笔记仓库，连接本机目录，检查 Git 作者与远端访问。模型需要使用该库时另行配置宿主路径；检查会话记录与自动引用开关。

未保存草稿、收藏和页面连接选择不会由 GitHub 搬过去。上传或下载的具体步骤与范围见[同步](同步.md)。
