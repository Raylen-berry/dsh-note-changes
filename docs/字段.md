# 创作记录字段

[返回首页](../README.md) · [文档导航](README.md) · [日常用法](创作.md)

本页说明 `prompt_asset_save` 写出的记录和 `creative_context_resolve` 的选择参数。日常使用可以直接向模型描述需要记录的内容、范围和来源。

## 收录参数

| 字段 | 含义与默认值 |
| --- | --- |
| `title`、`content` | 必填；记录名与正文，记录名会转为文件名 |
| `type` | 要求／偏好／参考／模板／经验，默认要求 |
| `binding` | 必须／优先／参考，默认参考 |
| `origin` | 用户明说／参考案例／AI推测，默认 AI推测 |
| `source_ref` | 用户原话、对话或文件锚点；用户明说时必填 |
| `scope_kind` | 适用范围，默认 `task_instance` |
| `scope_id` | 范围标识；`project` 和 `task_type` 必填 |
| `valid_until` | 可选到期日 `YYYY-MM-DD` |
| `supersedes` | 可选，被这条记录替代的旧记录 id |
| `task`、`aspect` | 生成方式与画幅，用于参考资料的场景筛选 |
| `model`、`engine`、`duration` | 模型、引擎和时长信息；不参与当前自动场景筛选 |
| `source` | 其他来源或文件位置；用户明说仍需单独给 `source_ref` |
| `tags`、`keywords` | 分类标签与检索词数组 |
| `vault` | 可选笔记库绝对路径 |

`id`、`schema_version`、`status` 由代码生成。用户明说、带来源锚点、且范围清楚时为生效；其余为草稿。成功使用过一次不会自行改变状态。

## 适用范围

| `scope_kind` | 标识与选择方式 |
| --- | --- |
| `global` | 全局；不需要 `scope_id`，可参与自动引用 |
| `project` | 必须给 `scope_id`；解析时 `project` 与它完全一致 |
| `task_type` | 必须给 `scope_id`；解析时 `task_type` 与它完全一致 |
| `task_instance` | 可不给 `scope_id`；仅通过 `explicit` 显式选用 |

本次记录缺少标识时可保存，默认仍为草稿；即使给了标识，也不会只因它与会话 id 相同就自动生效。

## 解析参数

| 参数 | 作用 |
| --- | --- |
| `project`、`task_type` | 与记录范围标识匹配；不给就不自动纳入该范围 |
| `explicit` | id、标题或路径数组；选用本次记录、草稿及需要显式读取的记录 |
| `task`、`aspect` | 仅筛选参考资料；明确错配时排除，留空不判错配 |
| `reference_budget` | 参考资料最多几条，默认 3；不裁剪必须项 |
| `vault` | 可选笔记库绝对路径 |

`binding` 决定约束强度，`type` 决定可达到的档位：参考类型一直是参考；模板和经验最多进入偏好，不能升级为必须项。AI 推测的必须项会降为参考并提示。

`supersedes` 只有在替代记录本次实际被纳入时才排除旧记录。重复 id、替代不存在的记录或自我替代会列入冲突提示；工具返回后仍需核对。

字段词表与行为以 [index.js](../index.js)、[creative-context.mjs](../lib/creative-context.mjs) 为准，边界检查见[开发](开发.md)。
