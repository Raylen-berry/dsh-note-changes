# 模型记录与日记

[返回首页](../README.md) · [文档导航](README.md)

除了手动编辑笔记，插件还为模型提供查日记、追加要点、保存创作记录和解析适用记录的工具。

| 工具 | 用途 |
| --- | --- |
| `vault_note_search` | 在 Git 已跟踪的日记目录中按关键词搜索；只读 |
| `vault_note_append` | 将要点追加到当天日记，写入后提交并尝试推送 |
| `prompt_asset_save` | 新建一条创作要求、偏好、参考、模板或经验记录 |
| `creative_context_resolve` | 只读解析当前任务适用的创作记录，返回内容和未采用原因 |

工具的路径可显式指定；不指定时按宿主路径优先级选择，详见[数据](数据.md)。在页面选择一个文件夹，不等于模型工具的默认路径也随之改变。

## 日记要点存在哪里

`vault_note_append` 追加到笔记库内 **`00-收件箱/日记/YYYY-MM-DD.md`**。可以让模型在工作结束时整理具体要点，再调用工具追加。

`vault_note_search` 使用 Git 检索已跟踪的日记，默认返回最多 30 行，上限 100 行。它的范围与工作区的全目录正文搜索不同，未跟踪的草稿不在这条检索入口中。

## 会话记录开关

设置中的 **会话结束时记录要点** 对应 `autoWriteOnSessionEnd`，缺省开启。关闭后，日记追加工具和自动兜底存根都停止写入；手动保存笔记仍可用。

当前兜底是监听模型进入空闲后等待约 3 分钟，再判断本轮是否已写过要点。需要补记时只写「待补充」存根，不会自动生成完整工作总结。进入空闲不等于关闭会话。

这个开关不控制创作记录收录或自动引用。创作记录的用法见[创作](创作.md)，字段和默认值见[字段](字段.md)。
