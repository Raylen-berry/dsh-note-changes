# 阅读与整理笔记

[返回首页](../README.md) · [文档导航](README.md)

## 工作区怎么读

在已有会话打开 **笔记**。左侧是文件树和搜索，中间是正文或编辑器，右侧是大纲与双链。长目录和链接列表各自滚动，正文单独滚动。

| 操作 | 用途 |
| --- | --- |
| 搜索标题与正文 | 找到当前目录中的笔记，包括未提交的文件 |
| 标签与属性筛选 | 用标签或常用 frontmatter 属性和值组合筛选 |
| 大纲 | 沿标题跳到正文位置 |
| 双链、出链与反向链接 | 打开相关笔记；同名文件有候选时由你选择 |
| 局部关系图 | 查看当前笔记周围的明确双链；不猜测同名歧义 |
| 孤立笔记 | 查找没有明确链接的笔记 |
| 收藏与最近打开 | 按笔记库保存在本机浏览器，便于再次打开 |
| 刷新 | 更新目录与搜索索引，底栏显示读取和复用情况 |
| 改动历史 | 查看 Git 提交改动过哪些 Markdown 文件 |

## 新建与编辑

点 **＋ 新建**，选择空白、每日或会议模板，也可以建立多级目录。「今日笔记」遇到同名已有文件时直接打开；新建不会覆盖已有笔记。

编辑器使用 Markdown 原文，保留 frontmatter 和双链。保存和快捷键、草稿恢复、冲突处理见[保存](保存.md)。

frontmatter 是文件开头 `---` 之间的属性。筛选支持顶层单值、内联列表与缩进列表；复杂 YAML 不参与筛选，但编辑时仍保留原文。

## 附件与公式

支持 `![[附件]]` 和 Markdown 相对附件路径，目标须在笔记库内。

| 类型 | 显示方式 |
| --- | --- |
| PNG／JPEG／GIF／WebP／AVIF | 库内图片预览 |
| MP3／WAV／OGG／M4A／MP4／WebM | 音频或视频播放，具体格式能力取决于浏览器 |
| PDF | 在本地新页入口打开 |
| 行内 `$...$` 与独立 `$$` 块 | 使用随插件分发的 KaTeX 排版 |
| 远程图片 | 显示可点击链接，阅读时不自动加载 |

单附件上限 20 MB；SVG 和其他主动内容不嵌入预览。SVG 可以在 Git 同步范围内，但这不表示可以在阅读器里预览。

## 大库与兼容范围

目录检索最多收集 2,000 篇笔记、2,000 个附件、500 个目录和 16 层深度，正文索引预算为 8 MB。单篇大于 512 KB 时正文不进入索引；达到预算会显示部分索引，不能把搜索结果当作全库内容。

刷新会复用宿主版本未变化的正文；索引缓存保存在内存中。隐藏目录与 `node_modules` 跳过，库外路径不会作为笔记或附件访问。

这里提供普通 Markdown 工作区，不运行 Obsidian 的第三方插件、Canvas 或 Dataview。超大笔记建议在 Obsidian 中打开，编辑限制见[保存](保存.md)。
